# Listou

Aplicativo de lista de compras colaborativo — organize e compartilhe suas listas de forma simples.

## Tecnologias

- React + Vite
- Supabase
- Deploy: Vercel

## Como rodar

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev
```

Acesse em `http://localhost:5173`
